# 后端待办任务清单 (Backend Todo Checklist)

目前在前端的 `/spaces` 空间详情页中新增了7个分区：

- 发帖区 (已实现)
- 即时聊天区
- 题库区
- 学校政策区
- 交易专区
- 课程评价区
- 教师评价区

除了发帖区，其余分区的后端尚未实现。请在接下来的开发中完成以下功能的接口：

## 1. 即时聊天区 (Real-time Chat)

- 需要实现基于 WebSocket 的聊天室功能。
- API 能够通过 `space_id` 获取历史聊天记录（分页）。
- 保存每条聊天消息 (Message Model)。

## 2. 题库区 (Question Bank)

- 可能是对 Resource(资料) 模型的一个特化，或者提供新的 Question 模型。
- 提供按知识点、难度等维度的搜索。

## 3. 学校政策区、交易专区、课程评价区、教师评价区

- 这些可以通过扩展 `Post` 模型的 `post_type` 或者 `tags` 来区分不同的业务。
- 根据各业务提供定制化的接口（比如评价区可能自带 1-5 星打分模型）。

## 要求：

- 结合本仓库现有的 `Tortoise ORM` 和依赖。
- 保证测试代码覆盖率。
- 各模型写好鉴权逻辑和 `owner` 权限判断。
